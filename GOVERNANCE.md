# Governance Boundary

This repository governs C2AI2X protocol semantics, JSON Schemas, illustrative
examples, conformance associations, consistency checks, and versioned static
assets.

It does not govern or provide platform APIs, execution runtimes, authentication
control planes, deployment configuration, service operations, or robot control.
Those concerns belong to independently governed implementations.

Changes to protocol assets should preserve the public snapshot boundary and be
reviewed for schema/example/conformance/integrity consistency.
