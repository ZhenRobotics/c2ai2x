# Protocol asset scope

This directory documents the static `c2ai2x-core/v1` protocol asset
snapshot: JSON Schemas, illustrative examples, the conformance manifest, and
the SHA-256 integrity manifest.

## Static assets only

The repository defines data shapes and reference fixtures. It does not define
a service interface, gateway behavior, execution behavior, deployment
configuration, credentials, production records, or service commitments.

## Integrity use

Use `../integrity.json` to compare each listed relative asset path with its
published SHA-256 digest. Verify a digest before relying on a copied asset.
Digest verification establishes that the checked file matches the snapshot
entry; it does not establish suitability for a particular implementation.
